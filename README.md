# Naz Foundation — Sit Entènèt

Louvri `index.html` nan yon navigatè pou wè sit la lokalman.

## Mete don yo an sekirite anvan lansman

1. Kreye yon kont biznis Stripe oswa PayPal nan non Naz Foundation epi verifye òganizasyon an.
2. Konekte kont bank fondasyon an **anndan platfòm peman an sèlman**.
3. Kreye yon *Payment Link* (Stripe) oswa yon lyen don PayPal.
4. Nan `index.html`, ranplase `REPLACE_WITH_YOUR_PAYMENT_LINK` ak lyen ofisyèl sa a.
5. Fè yon peman tès. Pa janm mete enfòmasyon bank oswa nimewo kat nan kòd sit la.

Montan ki sou paj la se gid vizyèl. Pou montan dinamik, kreye yon Payment Link ki aksepte montan kliyan an antre.

## Pibliye li

**Netlify:** konekte sou Netlify, chwazi **Add new site > Deploy manually**, epi glise dosye pwojè a sou paj la. Ou resevwa yon lyen piblik touswit.

**GitHub Pages:** voye fichye yo nan yon depo GitHub; nan **Settings > Pages**, chwazi branch prensipal la. GitHub ap bay adrès sit la.

Anvan pibliye, mete logo ofisyèl ak foto fondasyon an gen dwa itilize yo, verifye tèks yo, epi teste bouton don an.
